# Ticket 01 - Project Foundation

## Goal

프로젝트 메타데이터를 파일 기반으로 안정적으로 저장하고 복원한다.

## Scope

- 프로젝트 목록 조회
- 프로젝트 생성
- 프로젝트 상세 조회
- 프로젝트 수정
- 프로젝트 삭제

## Output

- `project.json` 저장 형식 확정
- 프로젝트 메타데이터 구조 확장

## Success Criteria

- 프로젝트를 만들고 다시 불러올 수 있다.
- 파일 저장 경로가 항상 `project_id` 기준이다.
- 나중에 가사, 오디오, LRC, 영상 파일을 붙일 자리가 있다.
