# Planning Docs

기획 관련 문서는 이 디렉토리 아래에만 둔다.

구조:

- `docs/planning/shared/` - 백엔드/프런트 공통 기준
- `docs/planning/backend/` - 백엔드 목표, 티켓, API 범위
- `docs/planning/frontend/` - 프런트 목표, 화면 단위 범위

원칙:

- 기획 문서는 코드 폴더에서 분리한다.
- 기능별로 나눠서 백엔드와 프런트가 같은 기준 문서를 보게 한다.
- 구현 전에 먼저 이 문서를 업데이트하고, 구현 시점에는 각 기능 문서만 읽는다.
