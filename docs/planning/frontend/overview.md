# Frontend Overview

로컬 AI Song Studio 프런트의 목표와 범위를 정리한다.

## 역할

- 프로젝트와 결과물을 보여준다.
- 가사 생성과 수정 흐름을 관리한다.
- 음악 생성 요청을 백엔드로 보낸다.
- 오디오 결과와 job 상태를 보여준다.

## MVP 범위

1. 프로젝트 생성
2. 감정선 입력
3. Ollama 가사 후보 생성
4. 가사 저장/수정
5. ACE-Step용 prompt 생성
6. 보컬 파일 선택 업로드
7. 생성 모드 선택
8. 백엔드에 음악 생성 요청
9. 생성된 wav 목록 표시
10. 브라우저 재생
